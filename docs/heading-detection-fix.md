# Heading and page-furniture migration

Previously, page-local rules classified a header before the document scan had evidence that it recurred. Contents used separate margin and title-repeat rules, so it could disagree with Book rendering or lose genuine openings. The new scan records compact source-item and relative row geometry, then confirms repeated furniture only with multiple pages and matching geometry/text. Confirmed items are excluded from heading evidence and reinterpreted as Source notes for the reader; single, ambiguous openings remain in the story. The original bytes and source runs remain intact.

The structure detector version refreshes saved scans. The layout version changes because moving furniture changes display offsets; reading positions with source anchors are remapped against the new projection. Older positions without a usable source anchor use the existing legacy fallback and cannot always preserve an exact character. The page-layout cache stays bounded and stores page-local source inputs, while saved scan evidence supplies the document-specific overlay on reopening. Partial scans keep evidence for resume and do not apply tentative furniture decisions; retried pages replace their earlier observations.

Regression checks cover recurrence, split and changing folios, mirrored rows, true top-edge headings, chapter identity, Source notes conservation, scan resume/retry, the display matrix and the supplied Frankenstein boundary. Rollback must restore both detector and layout behavior together; stored PDF bytes and source anchors remain the recovery basis, but offsets generated by one layout version should not be reused as exact offsets in another.

The recurrence model requires at least three distinct physical pages with exact normalized titles and similar viewport-relative geometry and type. Arabic folios must track physical page numbers; ambiguous explicit chapter labels without a separate folio require a separately detected opening. Short, ambiguous or nonmatching cases stay in the reading stream. These signals are heuristic: identical genuine openings and headers with indistinguishable geometry may remain ambiguous; OCR-tolerant matching and exhaustive rotated/mixed-size coverage are not claimed. Existing page-local rules still apply independently.
